# Design system

| Token | Value | Use |
|---|---|---|
| Ink | `#1c1e19` | Header, hero, headings |
| Paper | `#f6f1e7` | Main background |
| Burnt orange | `#be4f24` | Calls to action, emphasis |
| Ember | `#e8884d` | Accent on dark surfaces |
| Olive | `#303d2c` | Active filters, enquiry state |
| Parchment | `#e7e6d7` | Story and dividers |

Oswald 500/600/700 headings; Inter 400/500/600/700 body. Fonts are self-hosted through fontsource packages. These are design choices from the blueprint, not measured official brand specifications.

Layouts: three menu columns desktop, two tablet, one mobile. 560px and 800px are the main composition breakpoints; 1050/1295px refine spacing. Category controls scroll within their row on small screens. Native dialogs keep focus inside; focus rings are visible. Hero photo is eager/high priority; below-fold photos are lazy. Width/height reserve image layout space. Reduced motion disables decorative transitions.
