# Static Asset Placeholders (`public/images/README.md`)

Place approved, web-optimised photographs (`WebP`, `JPEG`, or `PNG`, each `<= 5 MiB`) and brand logo files in this directory.

- Never hotlink Instagram URLs.
- Until the business owner supplies confirmed photography and logo files (see `docs/content-checklist.md`), UI components must render visibly labelled `[Sample Photo Placeholder]` graphics with explicit `width` and `height` attributes.
